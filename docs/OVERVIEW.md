# AI Genesis Framework Overview

AI Genesis Framework (AGF) is a self-expanding, self-documenting system that
helps developers spin up projects from natural language intent. Even without
AI assistance, AGF provides reusable templates, clear documentation, and a
workflow that scales as the template library grows.

## Philosophy: Build a system that builds systems
- Templates capture repeatable project patterns.
- Documentation is generated alongside code so newcomers quickly ramp up.
- The CLI flow remains transparent and hackable while leaving space for future
  AI integrations.

## What you can do today
- List available templates and inspect their file layout.
- Generate runnable projects from natural language descriptions.
- Scaffold new templates and share them with your team or the community.
- Explore example outputs to understand how templates render.

## Where we're heading
- Optional AI co-pilots to propose structures, dependencies, and docs.
- Template marketplace for sharing patterns across ecosystems.
- Web UI for browsing, previewing, and launching generators.
