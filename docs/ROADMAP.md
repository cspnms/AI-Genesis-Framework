# Roadmap

## Near Term
- Expand template catalog (APIs, web apps, data pipelines).
- Add filtering and search to the CLI for large template sets.
- Provide optional post-generation checklists and lint recipes.

## Mid Term
- Integrate optional LLM helpers to suggest structures and docs.
- Web UI for browsing templates, previewing rendered files, and launching jobs.
- Template marketplace with rating and verification signals.

## Long Term
- Multi-language support (Rust, Go, Swift, Kotlin, etc.).
- Plugin system for adding generators, validators, and deployers.
- Collaborative workflows with remote registries and shared caches.
